- **Room type form > Website**: photo, description, display order, reviews.
- **Room form > Website**: include or exclude a room from online bookings
  (*Bookable on Website*).
- **Website > Configuration > Settings > Online booking times**: check-in
  and check-out times given to website requests (default 14:00 and 11:00).
- The website menu gets *Rooms* and *Gallery*; the portal home page gets a
  *Hotel Reservations* card.
