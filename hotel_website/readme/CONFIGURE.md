- **Room type form > Website**: photo, description, display order, reviews.
- **Room form > Website**: include or exclude a room from online bookings
  (*Bookable on Website*).
- **Website > Configuration > Settings > Online booking times**: check-in
  and check-out times given to website requests (default 14:00 and 11:00).
- The website menu gets *Rooms* and *Gallery*; the portal home page gets a
  *Hotel Reservations* card.
- **Website > Configuration > Settings > Hotel Website Layout**: the hotel
  homepage, and the company's name as brand, page title and copyright, on
  that website. Set on the first website at installation.
- **Website > Configuration > Settings > Online request expiry**: days a
  website request waits for the front desk before it is cancelled (default
  3; 0 cancels it only once the arrival date has passed). The guest is
  told. A daily scheduled action does it.
- **Website > Configuration > Settings > reCAPTCHA / Cloudflare Turnstile**:
  set one up to protect the request form from bots.
- **Room type form > Website > Reviews**: publish the reviews guests sent.
