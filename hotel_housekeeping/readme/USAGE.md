1. Configure the activities in *Hotel > Configuration > Activity*.
2. Open *Hotel > Housekeeping Services* and create a job for a room: the
   date, the clean type (daily, check-in, check-out) and the inspector.
3. Add the activities: housekeeper, start and end time.
4. Mark the room *Clean* (or *Dirty*). The inspector sets the quality and
   clicks *Done*; the inspection time is filled in if it is empty, and must
   be after the end of the cleaning.
5. The room form, list and board show the housekeeping status of the room
   (*Needs Cleaning*, *To Inspect*, *Ready*). The *Housekeeping* button on
   the room lists its jobs.
6. Print the activities of a room from *Hotel > Reports > Activity Report*,
   or select jobs and use *Print > Activity Detail*.
